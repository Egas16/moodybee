# 🐝 MoodyBee

MoodyBee adalah aplikasi berbasis web yang dirancang untuk membantu pengguna memantau, memahami, dan mengelola kondisi emosional (mood) mereka secara sederhana dan konsisten.

---

## 🎯 Tujuan & Manfaat

* Membantu pengguna mengenali pola perubahan mood harian
* Meningkatkan kesadaran diri (*self-awareness*) terhadap kondisi emosional
* Menjadi media refleksi diri melalui journaling
* Memberikan dorongan positif melalui quotes harian

---

## 🚀 Fitur Utama

### 1. Register & Login

* Pengguna dapat membuat akun baru melalui fitur registrasi
* Login digunakan untuk mengakses data mood secara personal

### 2. Mood Tracking

* Pengguna dapat memilih mood harian
* Mood disimpan dan ditampilkan dalam bentuk histori

### 3. Mood Calendar

* Menampilkan data mood dalam bentuk kalender bulanan
* Memudahkan pengguna melihat pola emosi dari waktu ke waktu

### 4. Self Journaling

* Pengguna dapat menuliskan perasaan atau kejadian yang dialami
* Membantu refleksi dan memahami penyebab mood

### 5. Mood Count

* Menampilkan statistik jumlah mood tertentu
* Membantu analisis kondisi emosional pengguna

### 6. Daily Quotes

* Menampilkan quotes acak setiap hari
* Memberikan motivasi dan energi positif

### 7. Activity Tracking

* Pengguna dapat mencatat aktivitas harian
* Aktivitas direpresentasikan dengan ikon

---

## 🛠️ Cara Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/username/moodybee.git
```

### 2. Masuk ke Folder Project

```bash
cd moodybee
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Jalankan Aplikasi

```bash
npm run dev
```

### 5. Akses di Browser

```
http://localhost:3000
```

---

## 🔁 Cara Fork Repository

1. Buka repository MoodyBee di GitHub
2. Klik tombol **Fork** di bagian kanan atas
3. Repository akan tersalin ke akun GitHub Anda
4. Clone repository hasil fork ke local
5. Lakukan perubahan sesuai kebutuhan
